# 佳佳食府原生小程序

该目录是原生 WXML / WXSS 小程序，AppID 来自已登录后台：`wx752cf08e1abaaac9`。支持分类、去重、新增/编辑、食材/调料/做法、次数/评分、收藏、菜单、采购清单、归档恢复和下厨历史。

未配置云环境时可本地使用。云端使用 `wx.cloud.callFunction` 到 `kitchen` 云函数，再以已验证的 Supabase JWT 访问现有数据库并遵守 RLS。没有使用 AppSecret、service_role 或数据库密码。微信 openid 不作为客户端可指定的数据库 owner_id。

4. Supabase Authentication → Emails → Magic Link 模板添加 `{{ .Token }}`，使邮件同时显示邮箱验证码和网页登录链接。保留原模板后再修改；目前未修改该模板。
